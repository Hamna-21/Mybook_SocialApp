# ✨ What is MYbook?

**MYbook** is a Facebook-inspired social networking web application created to explore how a social platform can be designed and structured from the ground up.

The project focuses on building a **clean social-media interface**, interactive frontend components, profile experiences, authentication screens, and the foundation for connecting the application with a SQL database and Node.js backend.

🎯 **Main Goal:**
Build the frontend experience first, while creating the structure required to evolve the project into a fully functional social networking platform.
